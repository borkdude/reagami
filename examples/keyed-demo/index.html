reagami reconciliation: OLD (no key support) vs NEW (keyed + LIS)

Both columns render the same 2000-row keyed list. Type some text into a few inputs in BOTH columns, then hit a button. OLD has no key support: it rebuilds on count change, so your text disappears, every dot's animation restarts in sync (a visible flash), and the render time is high. NEW reuses the nodes: your typed text stays put, the dots keep their own animation phase, and it is fast. Shuffle shows it best - watch where your typed text ends up.
